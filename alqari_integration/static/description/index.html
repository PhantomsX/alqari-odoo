Document AI for Odoo 17

Connect Odoo to Al-Qari for OCR, field extraction, document classification, validation, and human review. All processing runs on the Al-Qari cloud API at https://api.alqari.sa.

Upload & OCR

Upload PDFs and receipt photos from Odoo. Text and layout are extracted automatically.

Extract Fields

Pull invoice numbers, totals, dates, vendors, and custom fields into Odoo records.

Classify

Detect document type using configurable categories such as invoice, contract, or memo.

Validate

Enforce field rules like total > 10000 with clear PASS or FAIL results.

What you get

  • API key authentication to https://api.alqari.sa
  • Process Document wizard for PDF and image uploads
  • Field validation rules with configurable checks
  • Human review queue with email notifications
  • Stored API responses on each document record

Quick start

  1. Install the module and open Al-Qari → Configuration.
  2. Set API Base URL and your qari_... API key.
  3. Optionally configure Field Validation Rules.
  4. Use Al-Qari → Process Document to upload a file.

Requirements

Odoo 17, Python package requests, an Al-Qari API key (qari_...), and outbound HTTPS access to https://api.alqari.sa.

This is a free connector. Sign up for an Al-Qari account at alqari.sa to obtain an API key.
