Document AI for Odoo

Connect Odoo to Al-Qari for OCR, field extraction, document classification, validation, and human review — powered by the Al-Qari cloud API at https://api.alqari.sa.

Upload & OCR

Upload PDFs and receipt photos from Odoo. Text is extracted automatically.

Extract Fields

Pull invoice numbers, totals, dates, vendors, and custom fields.

Classify

Detect document type using configurable categories.

Validate

Enforce field rules like total > 10000 with PASS/FAIL results.

Quick start

  1. Install the module and open Al-Qari → Configuration.
  2. Set API Base URL (https://api.alqari.sa) and your qari_... key.
  3. Optionally configure Field Validation Rules.
  4. Use Al-Qari → Process Document to upload a PDF or image.

Requirements: Odoo 17, Python requests, an Al-Qari API key (qari_...), and outbound HTTPS access to https://api.alqari.sa.

Support: alqari.sa
